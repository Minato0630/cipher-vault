CipherWing Guide & FAQ

What is CipherWing?

CipherWing is a secure client-side file cryptor. It encrypts and decrypts files locally in your browser memory using AES-256-GCM. No data is ever uploaded to any server.

How does it compare to other tools (like SEND)?

  • Modern Cryptography: Other tools use legacy, weak ciphers like DES and 3DES. CipherWing uses industry-standard AES-256-GCM.
  • Size Limitations: Most web encryptors limit files to 10MB or 15MB. CipherWing uses chunked streaming web workers to process files up to 2GB+.
  • Zero Servers: Many encryptors upload files to servers. CipherWing runs 100% locally and offline in this browser tab.

How to encrypt files?

Select "Encrypt Mode", drop or browse your files, enter a secret password (you can use our password generator), and click "Encrypt Files".

How to decrypt files?

Select "Decrypt Mode", drop your encrypted `.enc` files, enter the exact password used during encryption, and click "Decrypt Files".

What is "Keep files in local history"?

When enabled, CipherWing stores processed output file Blobs in your browser's local IndexedDB database. You can instantly download them later from the history panel without re-processing them. This data is private and scoped to your profile.
