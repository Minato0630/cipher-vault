CIPHERWING

Offline-Only client-Side File Cryptographic Suite

AES-256-GCM PBKDF2 600K 100% Client-Side

Project Overview

CipherWing is an offline-first file encryption and decryption application that runs directly inside browser memory. By leveraging web standards, it provides high-strength data protection without uploading data to external servers, delivering 100% client-side privacy.

Problem Statement

Existing web-based file encryptors pose substantial data leakage risks by uploading source files to backend servers for processing. Additionally, many tools use outdated, insecure ciphers (e.g. DES) and suffer from strict file-size constraints (10-15MB) due to naive in-memory loading limits.

Objective & Stack

To construct a standalone, high-performance offline suite capable of processing files up to 2GB+ using chunked streaming, while isolating user sessions via IndexedDB vaults.

System Metrics

  • 0% Data Leaks: Zero server communication ensures full privacy.
  • 2GB+ Chunking Limit: Seamless 1MB slice streaming.
  • PBKDF2 Security: 600,000 hashing iterations matching OWASP standards.
  • Dual Theme Sync: Seamless WebGL color switching between dark & light themes.

Future Scope

Future developments focus on implementing WebRTC P2P direct transfers to share encrypted files directly between browser tabs without intermediate storage servers, and integrating multi-threaded Web Workers for parallel batch processing.
